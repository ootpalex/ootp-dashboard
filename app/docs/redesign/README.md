# Redesign — "Night Scorecard" (graphite)

Review package for the visual redesign. **Batch 0 (foundation) is wired in; batches 1–7 are not yet.** Data access and
component logic are out of scope (see `app/CLAUDE.md` accessor rules).

| File | What it is |
|---|---|
| `MIGRATION_PLAN.md` | The plan: token model, 8 batches with gates, verification greps, rollout. Start here. |
| `MIGRATION_INVENTORY.md` | Per-file evidence: all 49 styled files, old colour → new token in context, structural rework list (B.1–B.15), batches, open questions. |
| `../../src/theme.js` | **Batch 0 landed (2026-08-23):** the token module now lives in the app — `TOKENS`, encoding maps, helpers (compatible API + new chip helpers), restyled `S`; breaking changes listed at the top of that file with call sites. |
| `tokens.css` | Reference copy; the live file is `app/src/tokens.css`, generated by `gen-tokens-css.mjs` from `app/src/theme.js` (imported in `main.jsx`). |
| `../prototype.css` | **Batch 7 landed:** rewritten to the new system, same class API (for the `lavish-prototype` skill). |
| `CHECKS.md` | Contrast tables produced by `contrast.mjs` (text tokens, grade ramp, tier pills, z-heat, level chips). |
| `mockup/night-scorecard.html` | The approved mockup (Free Agent Finder, real SSB data). Top-right "Ground" control is a review control — graphite is the decision. |
| `mockup/*.report.md` | Token/encoding report for the night-native build and the Scorecard layout report. |
| `mockup/shots/` | 1440 px renders of the approved mockup. |

Regenerate after editing `app/src/theme.js`:
```bash
node app/docs/redesign/gen-tokens-css.mjs > app/src/tokens.css
node app/docs/redesign/contrast.mjs > /tmp/checks.out   # paste into CHECKS.md under the header
```
