# Direction 2 — Scorecard

## Thesis (one sentence)
A printed scorecard crossed with a Savant leaderboard — cream paper, ink type, ruled column-group boxes and exactly one red pencil — that reads like a sheet a GM hands across the table, with a night-scorecard twin (ink-navy paper, same rules) behind a fixed Day/Night toggle.

## Reference world (2–4 touchstones, what each contributes)
- **Baseball Savant** — light ground, filled percentile pills (the FV tier chips and the z-heat cells), clean sans, colour carried by the data not the chrome.
- **A printed scorecard** — ruled boxes: every panel is a 1px ink-bordered box with a titled header bar; tables carry thin vertical rules between column *groups* (identity | value | development | health | contract) rather than between every column; the 2px ink rule under the h1; no shadows anywhere.
- **FanGraphs leaderboards** — density: 29px rows, 12–12.5px numerals, very light zebra, sticky headers, no card-within-card chrome.
- **Strat-O-Matic player cards** — the bordered box with a titled header strip (title left, count/state right); the left "paper panel" sidebar with the league/team/date block at top.

- CVD note: the grade ramp is ordered by luminance *and* weight, not hue — on paper it steps 8.97 (20) → 5.72 → 4.98 → 4.65 → 4.96 → 5.12 → 5.68 → 6.34 → 11.64 (80) contrast, so even a deuteranope sees dark-bold ends and lighter-regular middle, and the two bold ends are told apart by hue *plus* 80 being the heaviest weight and much darker than 20. z-heat uses red vs blue (not red vs green), and magnitude is saturation plus a direction (bar side) in the needs table. The level ladder is pure luminance. Proneness repeats the weight rule (ends bold). Position chips are identified by label text; colour is a secondary cue.

## Layout model
- **Nav**: 200px sticky paper sidebar, 1px line-2 right rule. Brand "SSB" (Archivo 800) with "GM Dashboard" suffix; a bordered League / My Team / Game Date block with underlined value rows; pages as plain Archivo Narrow text, active page = bold with a red pencil ✓ tick at left; Settings pinned at the bottom above a hairline.
- **Page header**: h1 + one-line context deck (numbers bolded) left, actions (secondary "Export CSV" + primary red "Save view") right, 2px ink rule beneath. The fixed Day/Night toggle sits on the same line at far top-right; the action group reserves 108px so nothing collides.
- **Top row**: 1fr / 2fr grid of two scorecard boxes. Team Positional Needs (POS | Now bar | Score+Rank heat cells, footnote row). Smart Rank Adjustments: four ruled toggle rows that fill the box.
- **Board**: one scorecard box — header strip (title + count left, sort state right), then the filter row *inside* the strip (panel-2 ground): position select, search with inline magnifier, Age / Pro Yrs min–max ranges, "Gap fills only" switch pushed right. Table has sticky Archivo Narrow headers, the sorted header gets the red pencil underline, group rules at FV / Dev% / Prone / Salary, very light zebra, NEED rows tinted accent-bg-2 with the 11px NEED tag; pagination strip at the foot (Prev disabled, Next live).
- **Player modal (described, not built)**: a centred 960px scorecard box over a 40% ink scrim — header bar with name / POS chip / Lvl chip / FV pill left and close right, tabs as a panel-2 strip directly under it (sorted-underline style for the active tab), body in 8px-grid sections with Savant-style percentile pills (the same FV tier fill rule, width = percentile) and a ratings table with the same group rules.
- **Cards**: yes — every section is a bordered scorecard box; no nested cards, no shadows.

## What makes it not the default Claude look (one paragraph)
The ground is cream paper, not slate; the only accent is a single red pencil used five ways (tick, sort underline, primary button, on-switch, NEED tag) instead of blue-500 on everything; there is no gradient, no translucency, no blur, no shadow, one 3px radius, and 1px ink borders that read as printed rules; headers are 12px Archivo Narrow in title case rather than 11px uppercase tracked; all type is one family (Archivo + its Narrow cut) with no monospace for numerals; the tables carry scorecard column-group rules and a centre-zero bar chart that no generic dashboard template ships; and the dark twin is an ink-navy "night scorecard" built from the same rules rather than a slate palette swap.

## Cost & risk
- theme.js / inline-style scope: every colour in `theme.js` (FV_TIER_COLORS, zToColor, posColor, levelColor, proneColor, devPctColor, gradeToColor) becomes a token lookup that must switch on theme; the hardcoded Tailwind hexes inside component inline styles (Dashboard.jsx sidebar, shared.jsx Toggle/PillBtn/Pagination, FreeAgentFinder.jsx table cells) need to move to CSS variables so the Day/Night flip is a one-attribute change. Expect ~40 token names and one `data-theme` attribute on `<html>`; zToColor becomes a mix-percentage plus one of two endpoints.
- Structural rework (not just tokens): the table header needs column-group metadata (which columns start a group) — a small per-view array, applied as a class on `<th>`/`<td>`; PositionalStrengthTable gains the centre-zero bar cell (one pseudo-element pair, no new DOM); the board's filter bar moves inside the section header strip; the Toggle component gets the ruled-row variant; FV tier badge becomes a filled pill; the level badge becomes a filled ladder with the INT outlined exception. Sidebar layout is unchanged in structure.
- Readability at density: 12px Archivo numerals are crisp at 29px rows; the risk is the 40/45 ochre-olive stops, which sit at 4.6–5.0:1 on paper and ~4.3–4.5:1 on the zebra stripe — legible but the dimmest part of the ramp, which is deliberate (the middle of 20–80 should recede). Eye fatigue at night: the default is light, so the toggle matters — the dark twin keeps panel at #18212c (not pure black), text at #e9e4d8 (warm, 12.8:1), and drops the saturated red to #e0564a; NEED rows in dark use a low-chroma brown tint so twelve tinted rows don't glow. A long light session beside OOTP's own dark UI may feel bright; that is the known cost of a light-native direction.

- Horizontal scroll at 1440: **no** — verified in the Claude browser pane at 1440×1000 (`document.documentElement.scrollWidth` = 1440 in both themes, widest table 1190px inside a 1240px content column; 24-column density table fits with 5px cell padding, table-layout auto) and with headless Chrome full-page renders of both themes (dir-2-shot-light.png / dir-2-shot-dark.png in this directory). Browser-pane screenshots were intermittent because the pane is shared with the sibling agents, so the visual pass was done on the headless renders.
- Smallest font: 11px (sidebar field labels, the NEED tag, the "Only positions below league avg" toggle caption); table body 12–12.5px; headers 12px.
- Body text contrast on panel: light #1c2531 on #fffdf8 = **15.2:1**; dark #e9e4d8 on #18212c = **12.8:1**. Secondary text 7.4:1 light / 7.8:1 dark; muted 4.8:1 light (4.4:1 on the panel-2 strips) / 5.1:1 dark.
- Dimmest grade stop: light 45 #6c7a1d = **4.65:1** on panel (4.26:1 on panel-2; 40 ochre 4.98:1); dark 20 #ef7168 = **5.59:1** on panel. Tier pill text: ≥4.65:1 light, ≥6.09:1 dark. Solid z cells: paper text on #b7352b 5.8:1 / on #1f5fa8 6.3:1; dark ink text on #e0564a 4.7:1 / on #5f95e6 5.8:1.
- Deviations from the brief: (1) the filters sit in a second row of the board header strip rather than on the same line as the title — 1,192px was not enough for title + five controls at readable sizes; (2) three small state labels were added to header strips ("z vs league · 2043", "2 of 4 on", "Sorted by Smart, descending") plus the "GM Dashboard" brand suffix — chrome text, no data values invented; (3) the two page-header buttons ("Export CSV", "Save view") are added to show primary vs secondary states as the brief asks.
